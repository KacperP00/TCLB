# Intermediate engineering project

- topic: validation of TCLB solver - shallow water model by experimental benchmark
- the Monsalve et al. article was chosen: perfect absorbtion by Helmholtz resonance
- it was performed by recreation of the canal, frequency sweep and python analysis of results
- python analysis was based on Fourier transform (including complex numbers) and fitting to the equation for eta. 
- it returned all measured values from which the reflection coefficient was the most important - it was plotted against frequency and compared with the article.
